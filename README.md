# Taskflow

A full-stack task management application built with Flask, REST APIs, SQLite, HTML, CSS, and JavaScript.

Taskflow allows users to create, view, update, search, filter, sort, and delete tasks through a clean web interface backed by a Flask REST API.

## Live Demo

[Taskflow Live Demo](YOUR_DEPLOYED_URL)

## Features

- Create tasks
- View all tasks
- View individual tasks
- Update tasks using PATCH
- Delete tasks
- Task status management
- Search tasks
- Filter tasks by status
- Sort tasks
- Recent tasks section
- Overview dashboard
- Form validation
- Error handling
- RESTful API
- SQLite database
- Responsive frontend
- Toast notifications
- Confirmation modals
